# Prior art and name check

Checked 2026-11-13 through public official pages. These are product comparisons, not patent or trademark clearance.

- [Paperloom](https://paperloom.app/) and [Paperloom.io](https://www.paperloom.io/) already use the proposed name. Renamed the working product **Evidraft Lab**. A quoted web search for that exact name returned no direct result in this session; this does not establish legal availability.
- [Quarto inline code](https://quarto.org/docs/computations/inline-code.html): computed values in narrative already exist. This prototype adds an explicit browser interaction for inspecting and updating immutable evidence references.
- [Manubot](https://manubot.org/): collaborative, versioned Markdown publication already exists. This prototype is a local browser desk, not a replacement publishing system.
- [Yjs](https://docs.yjs.dev/getting-started/a-collaborative-editor): an appropriate future CRDT foundation; it is not implemented here.

Hypothesis to validate with researchers: explicitly separating stale evidence, arithmetic errors and unsupported claims reduces submission mistakes. No user study has been run. The full planned combination has not been proven unique. MLflow/DVC/W&B and Overleaf comparison remains open for the production phase.
