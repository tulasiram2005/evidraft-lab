# Visual system

Tokens live in `apps/web/tokens.css`: warm paper/olive ink/burgundy accent; deep botanical night theme. States use moss, amber and brick with text and icons in addition to color. Serif manuscript; sans interface; monospace evidence IDs. System fonts avoid runtime external calls; Fontsource remains open.

Spacing is primarily 4px multiples; small labels use optical exceptions. Corners 2px. Hairlines establish groups. Paper has a restrained offset edge; the edition archive uses a CSS paper stack. Motion is 160–200ms and disabled for reduced-motion preference. Lucide icons use 1.6px strokes throughout.

Keyboard: focus outlines, native buttons, modal focus loop, Escape close and Cmd/Ctrl+Enter check. Mobile navigation, single-column paper below tablet width, and overflow-safe ledger. Formal axe audit is still required.

Plain microcopy names the cause and next action. Local-only, synthetic and unsigned states are explicit.
